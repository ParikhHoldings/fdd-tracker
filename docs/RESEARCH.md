# Research

## Competitors / alternatives
- manual FDD review workflows
- general-purpose PDF comparison tools
- consultant-led manual monitoring processes

## Insights
- the pain is specific: meaningful document change detection, not generic PDF handling
- operational trust depends heavily on alert reliability and explainability
- a free tool helps with acquisition, but the durable value is in monitored change workflows

## Open questions
- which buyer segment pays fastest for monitored FDD alerts?
- what exact summary format creates the strongest perceived value?
- what sourcing/legal/ops assumptions need to be explicit before broader growth?

## Opportunities
- use growing observability and diagnostics as part of the product’s trust story
- convert the free tool into a sharper acquisition layer for the SaaS product
- keep documentation tightly synchronized with the live repo so revenue moves faster
