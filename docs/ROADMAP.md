# Roadmap

## Current themes
1. MVP hardening and observability
2. trustworthy monitored alert workflow
3. revenue-ready monitored SaaS path

## Near-term priorities
- keep hardening run/alert/ops observability
- maintain product truth between live repo and portfolio control layer
- tighten the bridge from free tool + monitored workflow into a credible paid product narrative

## Next major milestones
- run/alert summaries are operationally trustworthy and easy to inspect
- one reliable end-to-end change-detection flow is documented clearly
- operational diagnostics support confident pilot/internal use
- paid-product path is clearer from verified product behavior

## Risks / dependencies
- legal/operational nuance around document sourcing still matters
- trust can erode quickly if alert summaries are noisy or opaque
- product hardening could outrun narrative clarity if not documented well
