# Marketing

## ICP
- franchise buyers doing serious diligence
- franchise brokers and consultants who monitor many systems
- operators/analysts who need faster visibility into FDD changes

## Positioning
FDD Tracker helps users monitor franchise disclosure documents and understand meaningful changes faster than manual document review.

## Main pain points
- FDD review is slow and repetitive
- meaningful changes can be missed or discovered too late
- manual monitoring does not scale well across many brands/documents
- generic document tools do not solve the franchise-specific monitoring problem cleanly

## Channel ideas
- free tool as top-of-funnel proof and acquisition wedge
- founder-led outreach to franchise consultants/brokers/operators
- content around how to monitor FDD changes more intelligently
- product proof built from monitored runs and clear alert summaries

## Content angles
- stop manually comparing franchise disclosure documents line by line
- know what changed before it becomes a missed risk
- franchise document monitoring with operational visibility, not just file storage

## Current experiments
- sharpen the bridge between the free tool and the monitored SaaS path
- align go-to-market claims with what the live product now actually supports
