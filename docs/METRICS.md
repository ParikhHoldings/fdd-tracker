# Metrics

- number of reliable monitored runs
- diff/change summary usefulness
- alert delivery reliability
- operational observability completeness

## Growth
- free tool usage

- time to first monetizable monitored workflow
- pilot/customer interest in paid alerts
- revenue-path clarity from current MVP

## Reliability / quality
- ingestion success rate
- alert dispatch success/fallback rate
- run-summary diagnostic completeness
